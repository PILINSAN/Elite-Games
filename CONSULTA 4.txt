::Requisito funcional: El sistema debe calcular cuánto ha gastado cada usuario en sus pedidos, junto con su compra promedio, máxima y mínima.
Enunciado: Mostrar el nombre completo del usuario, el total gastado, el promedio, la compra máxima y la compra mínima.


MariaDB [elite_games]> SELECT CONCAT(u.nombre, ' ', u.apellido) AS usuario,
    ->        SUM(dp.cantidad * dp.precio_unitario) AS total_gastado,
    ->        AVG(dp.cantidad * dp.precio_unitario) AS promedio_compra,
    ->        MAX(dp.cantidad * dp.precio_unitario) AS compra_maxima,
    ->        MIN(dp.cantidad * dp.precio_unitario) AS compra_minima
    -> FROM usuarios u
    -> INNER JOIN pedidos p ON u.idUsuario = p.idUsuario
    -> INNER JOIN detalle_pedido dp ON p.idPedido = dp.idPedido
    -> INNER JOIN juegos j ON dp.idJuego = j.idJuego
    -> GROUP BY u.idUsuario, u.nombre, u.apellido
    -> ORDER BY total_gastado DESC;
