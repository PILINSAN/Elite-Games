::Requisito funcional: El sistema debe permitir analizar los precios de los juegos por plataforma, categoría y proveedor, aplicando ajustes matemáticos.
Enunciado: Mostrar el juego, la plataforma, la categoría, el precio original, el precio redondeado, el precio techo, el precio piso y el resto de dividir el id del juego entre el id de la categoría.

MariaDB [elite_games]> SELECT pr.razon_social AS proveedor,
    ->        j.nombre AS juego,
    ->        c.nombre AS categoria,
    ->        pl.nombre AS plataforma,
    ->        jp.precio
    -> FROM proveedores pr
    -> RIGHT JOIN juegos j ON pr.idProveedor = j.idProveedor
    -> INNER JOIN categorias c ON j.idCategoria = c.idCategoria
    -> INNER JOIN juego_plataforma jp ON j.idJuego = jp.idJuego
    -> INNER JOIN plataformas pl ON jp.idPlataforma = pl.idPlataforma
    -> ORDER BY j.nombre;
