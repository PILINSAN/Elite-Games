::Requisito funcional: El sistema debe permitir consultar los pedidos realizados en un mes específico, junto con el usuario y los juegos comprados.
Enunciado: Mostrar el usuario, el número de pedido, el mes del pedido, el juego y la cantidad, filtrando por el mes de abril.

MariaDB [elite_games]> SELECT CONCAT(u.nombre, ' ', u.apellido) AS usuario,
    ->        p.idPedido,
    ->        MONTH(p.fecha_pedido) AS mes_pedido,
    ->        j.nombre AS juego,
    ->        dp.cantidad
    -> FROM usuarios u
    -> INNER JOIN pedidos p ON u.idUsuario = p.idUsuario
    -> INNER JOIN detalle_pedido dp ON p.idPedido = dp.idPedido
    -> INNER JOIN juegos j ON dp.idJuego = j.idJuego
    -> WHERE MONTH(p.fecha_pedido) = 4
    -> ORDER BY p.fecha_pedido;
