::Requisito funcional: El sistema debe mostrar el detalle completo de los pedidos cuyo total sea mayor al total del pedido más pequeño registrado.
::Enunciado: Mostrar el usuario, el número de pedido, el juego comprado, la cantidad y el total del pedido, excluyendo el pedido con el valor mínimo.

MariaDB [elite_games]> SELECT CONCAT(u.nombre, ' ', u.apellido) AS usuario,
    ->        p.idPedido,
    ->        p.total
    -> FROM usuarios u
    -> INNER JOIN pedidos p ON u.idUsuario = p.idUsuario
    -> WHERE p.total > (
    ->     SELECT MIN(total) FROM pedidos
    -> )
    -> ORDER BY p.total DESC;
