::Requisito funcional: El sistema debe mostrar el inventario de los juegos cuyo stock disponible sea menor al promedio general de stock, junto con su proveedor y categoría.
::Enunciado: Mostrar el juego, la categoría, el proveedor y el stock disponible, solo para los juegos con stock por debajo del promedio.

MariaDB [elite_games]> SELECT j.nombre AS juego,
    ->        c.nombre AS categoria,
    ->        pr.razon_social AS proveedor,
    ->        inv.stock_disponible
    -> FROM inventario inv
    -> INNER JOIN juegos j ON inv.idJuego = j.idJuego
    -> INNER JOIN categorias c ON j.idCategoria = c.idCategoria
    -> INNER JOIN proveedores pr ON j.idProveedor = pr.idProveedor
    -> WHERE inv.stock_disponible < (
    ->     SELECT AVG(stock_disponible) FROM inventario
    -> )
    -> ORDER BY inv.stock_disponible ASC;
