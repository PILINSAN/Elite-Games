::Requisito funcional: El sistema debe listar a los usuarios que jamás han generado un PQRS, junto con la información de sus pedidos y juegos comprados (si existen).
::Enunciado: Mostrar el usuario, el correo, el número de pedido y el juego comprado, solo para quienes no aparecen registrados en la tabla pqrs.

MariaDB [elite_games]> SELECT CONCAT(u.nombre, ' ', u.apellido) AS usuario,
    ->        u.email,
    ->        j.nombre AS juego,
    ->        dp.cantidad,
    ->        (
    ->            SELECT COUNT(*)
    ->            FROM pqrs pq
    ->            WHERE pq.idUsuario = u.idUsuario
    ->        ) AS cantidad_pqrs
    -> FROM usuarios u
    -> LEFT JOIN pedidos p ON u.idUsuario = p.idUsuario
    -> LEFT JOIN detalle_pedido dp ON p.idPedido = dp.idPedido
    -> LEFT JOIN juegos j ON dp.idJuego = j.idJuego
    -> ORDER BY usuario;
