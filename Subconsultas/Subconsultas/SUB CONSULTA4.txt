::Requisito funcional: El sistema debe identificar a los administradores que administran más juegos que el promedio de juegos administrados por administrador.
::Enunciado: Mostrar el nombre completo del administrador y la cantidad de juegos que administra.

MariaDB [elite_games]> SELECT CONCAT(a.nombre, ' ', a.apellido) AS administrador,
    ->        COUNT(aj.idJuego) AS cantidad_juegos
    -> FROM administradores a
    -> INNER JOIN admin_juego aj ON a.idAdmin = aj.idAdmin
    -> GROUP BY a.idAdmin, a.nombre, a.apellido
    -> HAVING COUNT(aj.idJuego) > (
    ->     SELECT AVG(cnt.total_juegos)
    ->     FROM (
    ->         SELECT COUNT(idJuego) AS total_juegos
    ->         FROM admin_juego
    ->         GROUP BY idAdmin
    ->     ) AS cnt
    -> );
