::Requisito funcional: El sistema debe identificar los pagos cuyo monto sea mayor al promedio de montos pagados en toda la plataforma, junto con el detalle del juego comprado.
::Enunciado: Mostrar el usuario, el número de pedido, el juego comprado, el método de pago y el monto pagado, solo para los pagos por encima del promedio general.

MariaDB [elite_games]> SELECT CONCAT(u.nombre, ' ', u.apellido) AS usuario,
    ->        p.idPedido,
    ->        j.nombre AS juego,
    ->        pg.metodo_pago,
    ->        pg.monto
    -> FROM pagos pg
    -> INNER JOIN pedidos p ON pg.idPedido = p.idPedido
    -> INNER JOIN usuarios u ON p.idUsuario = u.idUsuario
    -> INNER JOIN detalle_pedido dp ON p.idPedido = dp.idPedido
    -> INNER JOIN juegos j ON dp.idJuego = j.idJuego
    -> WHERE pg.monto > (
    ->     SELECT AVG(monto) FROM pagos
    -> )
    -> ORDER BY pg.monto DESC;
