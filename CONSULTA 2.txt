::Requisito funcional: El sistema debe mostrar cuántos juegos administra cada administrador, incluso si no administra ninguno.
Enunciado: Mostrar el nombre completo del administrador, su rol y la cantidad de juegos que administra.


MariaDB [elite_games]> SELECT CONCAT(a.nombre, ' ', a.apellido) AS administrador,
    ->        a.rol,
    ->        COUNT(aj.idJuego) AS cantidad_juegos
    -> FROM administradores a
    -> LEFT JOIN admin_juego aj ON a.idAdmin = aj.idAdmin
    -> LEFT JOIN juegos j ON aj.idJuego = j.idJuego
    -> LEFT JOIN categorias c ON j.idCategoria = c.idCategoria
    -> GROUP BY a.idAdmin, a.nombre, a.apellido, a.rol
    -> ORDER BY cantidad_juegos DESC;
