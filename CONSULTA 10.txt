::Requisito funcional: El sistema debe calcular el total pagado y la cantidad de pagos por usuario, incluso si aún no han pagado nada.
Enunciado: Mostrar el usuario, la cantidad de pagos, el total pagado, el promedio de pago y la cantidad de artículos comprados.

MariaDB [elite_games]> SELECT CONCAT(u.nombre, ' ', u.apellido) AS usuario,
    ->        COUNT(DISTINCT pg.idPago) AS cantidad_pagos,
    ->        SUM(pg.monto) AS total_pagado,
    ->        AVG(pg.monto) AS promedio_pago,
    ->        COUNT(dp.idDetalle) AS items_comprados
    -> FROM usuarios u
    -> LEFT JOIN pedidos p ON u.idUsuario = p.idUsuario
    -> LEFT JOIN pagos pg ON p.idPedido = pg.idPedido
    -> LEFT JOIN detalle_pedido dp ON p.idPedido = dp.idPedido
    -> GROUP BY u.idUsuario, u.nombre, u.apellido
    -> ORDER BY total_pagado DESC;
